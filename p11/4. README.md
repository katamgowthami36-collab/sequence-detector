# Sequence Detector using Verilog HDL

## 📌 Project Overview

This project implements a **Sequence Detector** using Verilog HDL.

The circuit detects a predefined binary sequence from a serial input stream. In this project, the sequence **1011** is detected.

When the input sequence `1011` is received, the output `detected` becomes `1`.

## 🎯 Objectives

* Design a sequence detector using Verilog HDL.
* Implement the design using a Finite State Machine (FSM).
* Create a Verilog testbench.
* Verify the design through simulation.
* Analyze the output waveform.

## 🧠 Working Principle

The sequence detector uses an FSM to keep track of the previously received input bits.

For the sequence `1011`:

| State | Meaning          |
| ----- | ---------------- |
| S0    | No matching bits |
| S1    | Received `1`     |
| S2    | Received `10`    |
| S3    | Received `101`   |

When the circuit is in state `S3` and receives another `1`, the complete sequence `1011` has been detected.

Therefore:

```text
Input Sequence: 1 → 0 → 1 → 1
Output:         0   0   0   1
```

## ▶️ Simulation

Compile the Verilog source and testbench:

```bash
iverilog -o sequence_detector_sim src/sequence_detector.v testbench/tb_sequence_detector.v
```

Run the simulation:

```bash
vvp sequence_detector_sim
```

The simulation verifies that the detector produces an output when the sequence `1011` is received.

## 📊 Expected Result

When the input stream contains:

```text
1011
```

the output becomes:

```text
0001
```

The `1` indicates successful sequence detection.
